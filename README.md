# 拾片 · 玻璃侧边收纳 0.9.0

原生 macOS 应用：文字、复制的图片、系统截图统一收进玻璃右侧栏。

图片直接显示原图；标题固定使用蓝色思源黑体，正文使用黑色楷体，标签为淡蓝色。其他机器未安装相应字体时退回系统字体。每条内容使用独立的半透明圆角玻璃面板，带柔和高光与间隔；macOS 26+ 使用系统原生液态玻璃效果，较旧系统使用磨砂材质。

## 使用

打开 `dist/拾片.app`，菜单栏出现图文图标，无 Dock 图标。

- 复制文字或图片即自动收集；截图使用原来的 macOS 快捷键。新内容不会主动弹出侧栏。
- 鼠标碰到当前屏幕最右侧即展开，移开后立即开始收起，收起动画约 0.1 秒。顶部菜单栏不再触发展开。
- 按住内容拖到目标窗口：文字按完整原文传递，图片提供 PNG 和文件拖放格式。点击不再复制，复制操作保留在右键菜单。
- 文字右键查看全文；图片右键预览或另存；图文均可拖到其他应用。
- 悬停时在左上角显示取下按钮。内容按实际高度紧凑排列，使用鼠标滚轮或触控板连续上下滚动，无翻页。删除时内容保持大小，直接向右滑出侧栏；随后自动收拢空位。
- 菜单栏可暂停收集、切换系统截图接管、清空、退出。
- 最多 100 个图文片段。文字每条最多 1 MiB，图片输入最多 32 MiB、4000 万像素。
- 空白、文件和标记为私密/临时的内容不收集；同时包含文字和图片的复制优先收集文字。

## 待办与番茄钟

顶部「＋」可新建待办或打开番茄钟。通过「收纳／待办／专注」切换。

- 待办：新增、右键编辑、勾选完成、删除；删除后可用顶部回退箭头恢复上一条。已完成项排在下面。
- 番茄钟：默认专注 25 分钟、休息 5 分钟。支持暂停、继续、重置，可在「计时设置」中调整时长。完成一轮后手动选择开始休息或再专注一轮。
- 到时会播放系统提示音，菜单栏出现完成标记；不会主动弹出侧栏。
- 待办、时长设置和计时状态保存在本机。退出、重启或休眠不会让运行中的计时重新开始；暂停状态也会保留。

## 撤销删除

侧栏顶部的回退箭头、右键菜单或菜单栏的「撤销上次删除」，可以恢复上一次删除，连同原图和标注。恢复时保持原大小，从右侧向左滑回原位置。「取下全部」算作一次操作，可整批恢复。仅保留一次撤销，不做多级历史；下一次删除会替换旧撤销记录。撤销记录在本机保存，重启后仍可恢复。

此功能从 0.7.0 开始记录删除；升级前已经永久删除的内容不在撤销记录内。

## 标注

右键文字或图片，选择「编辑标注…」，可填写标题、多行备注和标签；标签用英文或中文逗号分隔。保存后标题和标签显示在内容下方，备注通过悬停提示查看。所有标注均为透明背景。

拖放及右键复制使用原文或原图，不附带标注。重新复制同一内容会保留标注；右键「清除标注」只移除标注。标注随历史记录保存和恢复，条目删除或到达数量上限时一并移除。

## 从旧版本切换

启动合并版会请求旧 Picline 退出，避免旧应用继续占用顶部。首次启动会迁移旧 Picline 当前挂着的图片，原图片文件不变。0.1 文字记录直接兼容。

截图接管默认开启，截图写入本应用临时收件目录，成功收入图文记录后移除该临时副本。正常退出或关闭接管会恢复此前截图位置、保存目标和缩略图设置；检测到用户另行修改某项设置时保留用户的新值。可通过菜单切换接管。

旧 Picline 的其他功能（例如任意文件夹监控、图片标注和自定义全局快捷键）暂未迁入。

## 存储

更名为「拾片」后继续使用原应用标识和原数据目录，已有内容与设置直接保留。

图文记录只保存在 `~/Library/Application Support/Textline/`：

- `history.json`：文字、图文顺序与图片引用。
- `Images/`：本应用管理的 PNG；上一次删除所需图片暂留供撤销，撤销记录被新删除替换后清理不再使用的副本。
- `Screenshots/`：截图临时收件目录。
- `last-deletion.json`：收纳条目的一次撤销记录。
- `productivity.json`：待办、番茄钟与待办删除的一次撤销记录。

无网络请求。首次启动不追溯系统剪贴板，也不扫描导入整个桌面。无需辅助功能或屏幕录制权限来读取剪贴板及系统截图文件。

macOS 14+，当前构建为 Apple Silicon，使用本机临时签名。

## 构建与验证

```sh
./scripts/build-app.sh
swift run Textline --self-test
```

自检使用独立剪贴板、临时目录、隔离的偏好域，验证图文收集与复制、去重、旧记录兼容、保存恢复、文件监控、截图导入及截图设置恢复，不修改用户的剪贴板或截图配置。

```sh
./dist/拾片.app/Contents/MacOS/Shipian --demo
```

追加 `--animation-test` 可检查文字和图片的向右滑出动画启动、结束与窗口回收。

示例模式展示文字与图片混排，不接管截图，不关闭旧 Picline，不使用用户的历史和剪贴板。

绳索绘制、无焦点悬浮面板和透明动画覆盖层参考并改写自 Alejandro Buján 的 Tendedero（MIT）。授权见 `ThirdParty/Tendedero-LICENSE.txt`。使用独立名称与图标。
